# Proyecto Final JS - Tienda de Botines

Página de venta de botines Es un simulador interactivo para el curso de Coderhouse, con productos cargados desde `data.json` y un carrito que guarda la info al recargar.

## Funcionalidades

- Carrito de compras funcional
- Agregar y eliminar productos del carrito
- Uso de `fetch` para traer los productos desde un JSON
- Guardado en `localStorage` para no perder el carrito al recargar
- Confirmación de compra con SweetAlert2
- Notificaciones al agregar al carrito con Toastify
- Diseño responsive para compu y móvil

## Librerías

- SweetAlert2: mensajes de confirmación
- Toastify: notificaciones al agregar al carrito

## Cómo probarlo

Abrir el proyecto con una extensión tipo `Live Server` para que el `fetch` al archivo `data.json` funcione sin error de CORS.
